🎬 MovieHub – React + Vite Movie App
A fully responsive movie and TV show web app built with ReactJS, Vite, Tailwind CSS, and Redux, powered by movie APIs. Users can explore trending movies, shows, seasons, and discover content based on weekly or daily popularity. 


🚀 Tech Stack
⚛️ ReactJS – UI library for building user interfaces

⚡ Vite – Fast development build tool

🎨 Tailwind CSS – Utility-first CSS framework for styling

🔄 Redux Toolkit – State management for API data and app state

🌐 TMDb API / Movie API – For fetching movies, shows, and trending data



📽️ Features
🔍 Browse Trending Movies (daily & weekly)

🎞️ View Popular TV Shows

🗓️ Discover content by Season and Current Releases

🧠 Clean state management with Redux Toolkit

💡 Fully responsive design with Tailwind CSS

⚙️ API integration for real-time data





📁 Folder Structure
/src
  ├── assets           # Static assets like images, icons
  ├── components       # Reusable components (Navbar, Card, etc.)
  ├── features         # Redux slices and API logic
  ├── pages            # Main page views (Home, Movies, Shows)
  ├── redux            # Store configuration
  ├── App.jsx          # Root component
  └── main.jsx         # Entry point


🛠️ Getting Started

1. Clone the repo
   git clone https://github.com/Gouravpatel007/Movie-Web-App?tab=readme-ov-file.git
   cd moviehub

2. Install dependencies
   npm install
# or
yarn

3. Add your API key
   Create a .env file in the root and add your movie API key:
   VITE_MOVIE_API_KEY=your_api_key_here
4. Run the development server
npm run dev
# or
yarn dev
